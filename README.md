# Data Cleaning Practice

A collection of data cleaning and preprocessing projects using **Python and Pandas**.

## Projects

- **Project 01 — Cafe Dataset**
- **Project 02 — Cafe Employee Dataset**
- **Project 03 — Cafe Zomato Dataset**
- **Project 04 — Cafe E-commerce Dataset**
- **Project 05 — Cafe Healthcare Dataset**

Each project contains a raw dataset and a Jupyter Notebook covering the cleaning and preprocessing steps.

## Tools

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Topics Covered

- Missing values
- Duplicate data
- Data types
- Inconsistent values
- Text cleaning
- Date and time formatting
- Data validation
- Data transformation
